# 🍃 FruitSense AI

### AI-Powered Fruit Freshness Detection using Deep Learning

FruitSense AI is a modern web application that uses **Convolutional Neural Networks (CNNs)** and **TensorFlow** to classify fruit images as **Fresh** or **Rotten** in real time. The application provides an intuitive interface for users to upload fruit images and instantly receive freshness predictions with confidence scores.

## ✨ Features

### 🧠 AI-Powered Detection

Uses a trained CNN model to identify whether a fruit is fresh or rotten.

### 📤 Single Image Prediction

Upload a fruit image and receive an instant prediction.

### 📦 Batch Processing

Analyze multiple fruit images simultaneously.

### 📊 Confidence Analysis

Displays confidence percentage and prediction certainty.

### 🎨 Modern User Experience

Custom-designed Streamlit interface with premium styling.

### 🔒 Privacy First

Images are processed locally during inference and are not stored.

### ⚡ Fast Inference

Optimized TensorFlow model for quick predictions.

---

## 🚀 How It Works

1. Upload a fruit image.

2. The CNN model preprocesses the image.

3. TensorFlow performs inference.

4. FruitSense AI predicts:

   * ✅ Fresh
   * ❌ Rotten

5. Confidence score and recommendations are displayed.

* Color variations
* Surface defects
